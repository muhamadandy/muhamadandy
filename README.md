# Jusa - E-Commerce Platform

Full stack e-commerce platform built with Next.js and PostgreSQL, 
featuring integrated payment processing via Stripe and PayPal.

🔗 **Live Demo:** https://jusa-gamma.vercel.app/

## Features
- User authentication (register/login)
- Product browsing with search & category filter
- Shopping cart management
- Image upload for products
- Payment integration (Stripe & PayPal)

## Challenges & Learnings

a single checkout flow was the biggest challenge — each has different 
API structures and webhook handling for transaction verification.
